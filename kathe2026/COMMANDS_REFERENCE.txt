================================================================================
⚙️ PARAMETER EXPLANATIONS
================================================================================

--epochs N              Number of training passes (higher = better quality)
--use-bpcc              Add external Kashmiri-English data (recommended!)
--bpcc-samples N        How many BPCC samples to add (5K-15K)
--batch-size N          Sentences per batch (1-2 for 6GB GPU)
--grad-accum N          Accumulation steps (effective batch = batch × accum)
--lora-r N              LoRA rank (higher = more model capacity)
--lora-alpha N          LoRA alpha (typically 2× rank)
--lr N                  Learning rate (lower = more stable)
--warmup-ratio N        Warmup fraction (0.1-0.2)
--num-beams N           Beam search width (higher = better quality)

================================================================================
🎓 UNDERSTANDING THE PARAMETERS
================================================================================

Why 10 epochs?
   → Each epoch shows the model all 1,730 of your translations
   → More epochs = model learns patterns better
   → 10 epochs = sweet spot for quality without overfitting

Why BPCC augmentation?
   → Adds 10,000 more English-Kashmiri pairs
   → Prevents overfitting on your 1,730 examples
   → Helps model generalize better
   → Still prioritizes YOUR translation style

Why LoRA rank 64?
   → Higher rank = more model capacity
   → 64 is optimal for quality/memory balance
   → 128 for extreme quality (but takes longer)

Why batch size 2?
   → Your RTX 4050 has 6GB VRAM
   → Batch size 2 fits comfortably
   → Gradient accumulation makes effective batch = 16
